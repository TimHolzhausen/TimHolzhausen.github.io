    Why does the pen read through the design?

    The design is printed in cyan, magenta and yellow only, without black (K = 0). The pen only sees carbon black, so the code underneath stays readable. Dark text is therefore mixed from three colours and looks very dark brown rather than deep black. White cannot be printed.

    Not tested at print shops yet. It only works if the shop prints the colours as they are in the PDF. If it converts them and adds black, the pen cannot read the code under the design. The design goes into the PDFs; PNG backs stay without it. Order a test card first.

    How do you print?

    Cards per sheet
    Printing and cutting
    • 100 % / Actual size. Never “Fit to page”, no borderless printing.
    • Double-sided flipping on the long or short edge, both work: the layout is symmetric. Without duplex, print page 1, turn the paper over, then print page 2.
    • Laser printer, black as K. The pen only sees carbon black. A PostScript driver passes the dots through most cleanly.
    • Cutting, step 1: Front side up. Cut all horizontal lines at the side marks, working from the bottom up. That way the marks stay on the remaining piece until the last strip is off.
    • Step 2: Stack the strips with the top strip (the one with marks along its top edge) on top. Put the left paper edge flush against the guide, then cut vertically at the top marks.
    • Every sheet carries the same codes. If you print several sheets, each code appears more than once.

    Before you order

    No guarantee on dot strength. All three strengths were tested on office laser printers only, not at any online print shop. Presses, inks and papers differ: dots can bleed together or break away, and the pen may then not read the card. Order a small test run first, ideally one card per strength, and check it with your pen before ordering more.

    • Order a small test run first. Whether the pen reads the cards depends on the shop's press and ink, which you cannot see beforehand.
    • The dots must stay 100 % black (K). If the shop converts the file to RGB or rich black (C, M, Y and K mixed), the pen cannot see the code. The PDF sets the colour to pure K.
    • No scaling, no downsampling. The code needs the full 600 dpi. If the upload tool resizes the image or asks you to “fit” it, the dots get lost. PDF is the safest choice.
    • Matte, uncoated paper reads best. Glossy coating or lamination on the back can block the pen.
    • Normal strength is the safest bet for a press you have not tested yet.
    • One code per card design. Each of the 10 files carries a different code. Use a different one for every card set you order.
