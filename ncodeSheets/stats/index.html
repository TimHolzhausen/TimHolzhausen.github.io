Statistics

Visits and downloads of the Custom Sheets page and the Business Card Creator. The numbers live at GoatCounter; this page only shows them to someone who has the API key.

Where do I get the API key?
  1. Sign in at ncodesheets.goatcounter.com.
  2. Open User → API and create a new key.
  3. Tick only Read statistics. Paste the key here.

The key is stored only in this browser. It is never part of the website itself.
